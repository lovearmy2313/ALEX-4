ALEX - MAPS + CALLING UPDATE

This update keeps the existing ALEX interface and avatar. Maps and calling commands are integrated into the existing script.js.

INSTALL
1. Make a backup of your current ALEX folder.
2. Extract this ZIP.
3. Replace your current index.html, style.css, and script.js with the files from this ZIP.
4. Start your existing ALEX Flask server as usual, then open ALEX.
5. Allow microphone and location permissions when your browser asks.

VOICE / CHAT COMMANDS
- ALEX, open Google Maps
- ALEX, show me the route to Mumbai
- ALEX, search hospitals on Maps
- ALEX, show my current location
- ALEX, call +91 9876543210
- ALEX, WhatsApp call +91 9876543210

IMPORTANT CALLING LIMITS
- Normal calling opens the device phone dialer with the number. You must press Call yourself.
- WhatsApp calling opens the WhatsApp chat. Tap the phone icon in WhatsApp to place the call.
- A browser page cannot silently place calls or directly read your phone contacts. Contact-name lookup and native call permissions require a dedicated Android app integration and user-granted permissions.
- On a PC, tel: may not have a phone dialer available. These calling actions are intended for a phone browser/device.

Maps opens Google Maps in a new tab. Current-location commands ask the browser for location permission.
